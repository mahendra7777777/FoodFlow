# FoodFlow 🍽️

FoodFlow is a full-stack food delivery web application built using Java Spring Boot and React.js.

## Features

- Restaurant listing
- Restaurant search
- Restaurant details
- Menu browsing
- Food item display
- Responsive user interface
- RESTful backend API
- React frontend integrated with Spring Boot

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Web
- Maven
- REST API

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Vite
